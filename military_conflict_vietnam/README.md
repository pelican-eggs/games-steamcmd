# Military Conflict: Vietnam

## From their [Website](https://store.steampowered.com/app/1012110/Military_Conflict_Vietnam/)

It’s 1968 in Vietnam, the time to “Make War Not Love”. Side with the Viet Cong or U.S. Army in this intense, fast-paced FPS set during the Vietnam War. Experience classic combat or jump into co-op zombie mode. Choose from 300+ weapons of destruction.

This egg installs the native Linux 64-bit Source dedicated server (`srcds_run_x64`) via SteamCMD.

## Server Ports

Military Conflict: Vietnam servers require 1 port to be open. The port can be safely changed to any other. The SourceTV port can also be opened for spectators.

| Port      | default |
|-----------|---------|
| Game/rcon | 27015   |
| SourceTV  | 27020   |
